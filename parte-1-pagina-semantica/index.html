Proyectos

Proyecto 1: Sistema de Atención para Recibir Subsidio de Vivienda

Aplicación de escritorio que gestiona la asignación de turnos de atención para solicitantes de subsidio de vivienda. Los usuarios se cargan desde un archivo CSV y se organizan en una lista circular, mientras que dos colas de prioridad distribuyen los turnos dando preferencia a familias numerosas y, en caso de empate, a la fecha de solicitud más antigua. El sistema calcula tiempos de atención por servicio, genera estadísticas de los usuarios atendidos y no atendidos, y envía el turno asignado por correo electrónico.

Tecnologías: Java, JavaFX, estructuras de datos (colas de prioridad, listas circulares), procesamiento de archivos CSV, envío de correos con JavaMail.

Ver repositorio en GitLab

Proyecto 2: DiccionarioA

Aplicación de escritorio que organiza un diccionario de palabras por letra inicial (A-Z), usando estructuras de datos, especificamente pilas y colas implementadas desde cero para almacenar y recorrer las palabras. Las palabras se cargan desde un archivo alojado en una URL externa, y el sistema permite buscar si una palabra existe en el diccionario, reemplazar patrones de texto dentro de todas las palabras (mostrando cuántos reemplazos se hicieron y en cuáles palabras) y exportar el listado completo a un documento PDF. La interfaz gráfica se construyó con Java Swing.

Tecnologías: Java, Swing (NetBeans GUI Builder), estructuras de datos (pilas, colas), lectura de archivos por URL, generación de PDF con iText.

Ver repositorio en GitLab
